## What Vibey Is
AI marketing platform co-founded by Dylan Vanas and Sefy Tofan. Built self-funded. Max monthly dev cost during build: $11.5K.

## Three Product Pillars
1. **CMO Vibey:** coaches/marketers with scattered tools. Studio + flow side.
2. **Enterprise Vibey:** missions, brain, CEO-level features. Competes with Salesforce/HubSpot-level.
3. **Hardware:** future physical product layer (roadmap).
4. **Vibe Harness:** core IP layer. Policy, orchestration, context, materialization, tools. Competes with LangGraph, CrewAI.

## Product Roadmap & Features
- **Agent-to-agent communication:** manager agent initiates conversation with specialist agent, user watches in real-time.
- **Stripe integration:** financial analysis missions (one-click PDF output).
- **Slack, WhatsApp, Telegram:** Live integrations. Conversational interfaces outside the platform. 
- **Onboarding Flow:** New flow asks business questions and connects communication platforms instantly.
- **Unified Dashboards (priority):** Aggregates analytics across platforms (YouTube, Instagram) — highly requested by enterprise CMOs.
- **Vibe Autopilot:** proactive agent monitoring (signal-based, not heartbeat-based).
- **Automated Bug Tracking:** Dogfooding example where Sefy built Vibey's bug tracker inside Vibey, connected to the SDK so agents analyze GitHub code and Sentry logs directly.

Dylan is building a chat interface on the ROAS portal that routes tasks to Vibey's multi-agent system. Serves as proof of concept for the SDK vision and operational tool for his agency.

**Agency dependency reframe:** Pitch clients on replacing agency dependency with a custom-built Vibey solution. Turns retention problem into a Vibey enterprise sale. 

## User Funnel Insights
- **Drop-off problem:** Only 30-40% of interested people sign up. Over half show zero credit usage.
- **Key wow moment:** New user connected YouTube channel within 2 mins; Vibey pulled info, ran analysis, built script in under 5 mins.
