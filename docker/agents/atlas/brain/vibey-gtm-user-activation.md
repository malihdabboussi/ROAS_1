## The Core Problem (Documented)

Two validated conversion problems stand between Vibey and the 500-user investor milestone:

1. **Interest-to-signup gap:** Only 30-40% of people who express interest actually sign up (Dylan sent the link to 20-30 people, roughly 10-12 signed up).
2. **Signup-to-activation gap:** More than half of signed-up users show zero credit usage. Standard urgency tactics (limited enrollment messaging, free credits) did not meaningfully improve this.

The Conversion Architect Paradox: Dylan has built sold-out launch sequences for ROAS clients but has not pointed the same conversion architecture at Vibey's own user acquisition. The stated scaling plan (5 users/day from a waitlist) is a patience model, not a conversion model.

## GTM Shifts Under Active Consideration

**Waitlist gate:**
- Replace 'Start Free' on homepage with 'Join Waitlist'
- On confirmation page, show a waitlist position number with option to 'bump to the front' by prepaying $1,000 in credits
- Creates urgency, social proof, and upfront revenue simultaneously
- Personally referred testers get a special link with 10,000 free credits ($50 retail value)
- If someone clicks 'Log In' but has no account, redirect them to waitlist instead of creating an account; existing users go straight to dashboard

**Exclusivity-based content:**
- Dylan tested: posted Instagram video showing he built his sister's project in 10-15 minutes, said 'I'm gatekeeping this, message me if you want access, only if I like you'
- Finding: users who found the signup link on their own (without DMing) showed higher engagement — self-selected initiative correlates with activation quality
- Implication: gatekeeping creates demand; the right users self-select through the gate

**Use Vibey to build Vibey's own marketing:**
- Build the webinar, landing page, and email sequences using Vibey end-to-end
- Serves as a live capability demonstration and demand generation simultaneously
- Creates demo content while using the product — 'here's how we're automating this'
- Minimizes external tools; leans into Vibey for content creation
