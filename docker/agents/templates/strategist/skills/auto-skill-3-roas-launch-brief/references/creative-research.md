# Creative Research + Offer Menu — condensed from the ROAS ad-kit and offer frameworks

The valuable layers of roas-ad-kit / roas-ad-concepts / roas-ad-copy, distilled so this skill is self-contained. Reuse, don't reinvent.

## 1. Ad Library research (required, every run)

3-5 competitor/top-performer references before any creative recommendation. The live Meta Ad Library is JS-heavy and won't render through a fetch — web-search the competitors and the offer category instead ("[competitor] facebook ads", "[niche] webinar ads", ad-teardown articles), and flag references that need a manual Ad Library pull before creative kickoff.

Capture per reference: the hook · the identity angle (who it calls out) · creative format (static/video/carousel, founder-face vs text-on-texture) · the CTA · longevity signal (running a long time = working) · borrow or counter-position.

Date-stamp every reference. Summarize in tight lines — this feeds the angles.

## 2. Mechanism catalog (spread angles across these)

Generate angles across DIFFERENT mechanisms so each stops a different person:
- **Insider ritual** — the specific behavior only this avatar does (answering borrower texts at 9pm)
- **Quiet evidence** — proof shown, not claimed (the trend table, the worn armrest)
- **Split life** — before/after identity contrast
- **Mismatch** — success on paper, mess in reality
- **Belief reversal** — "the play isn't the problem, you stopped running it"
- **Stop/start** — stop doing X, start doing Y
- **Literalize the abstract** — make the invisible pain a visible image
- **Status reframe** — where they rank vs. where they could ("one of the 400")

Cover both poles: some fear/recognition, some aspiration/status.

## 3. Pressure tests (every angle passes before it ships as a recommendation)

- **Scroll test:** would this stop the actual avatar mid-scroll?
- **Mind-read test:** does it say something they think privately?
- **Could-be-anyone test:** if any coach could run it, it's too generic — kill it.
- **Screenshot test:** does the on-image idea work as a still?

## 4. Identity callouts (validate messaging)

4-6 lines, each "If you're a / If you've / If your" + a specific person and situation + the same offer underneath. Each line a DIFFERENT segment (role, life-stage, pain, hidden strength, belief, aspiration). Pull situations from the research and the call — never imagination.

## 5. Starter copy samples (candidates, not production)

- **3 landing page headlines** — big bold promise, about the reader, specific (headline is 80% of the budget)
- **3 Meta ad leads** — the first line of primary text, lands before the ~125-char fold, hook carries the click
- **Webinar campaigns: title + subtitle + 3 topic/session options** — sell the seat, not the offer

End on the want: every bullet, angle close, and headline resolves to the outcome stack (the title, the freedom, or both) — never to the mechanism alone. Mechanism opens the loop; outcome closes the sentence.

Human-copy standard on everything: no em dashes, no rhythmic triplets, no "it's not X it's Y," fifth-grade reading level, no round-number tells, sounds like a person.

## 6. The Offer Menu framework (WHAT IS AN OFFER, condensed)

Present each component as a selectable recommendation — keep / kill / edit:

1. **Product stack** — one-stop-shop, 3-5 NAMED components. Target reaction: "this is a LOT."
2. **Price + anchor** — anchored (vs. hiring, DIY, competitor receipts), then dropped. Show the anchor math.
3. **Bonuses** — each must kill a named objection or add speed/simplicity/certainty/urgency.
4. **Risk reversal** — a NAMED aggressive guarantee (e.g. "Better Than Money Back"). Match or beat the strongest competitor guarantee.
5. **Scarcity** — REAL only: room capacity, expiring bonus, price rise, application-only. Fake scarcity is banned.

**Verification rule:** before presenting the menu, check the call transcript and notes. Anything the client already decided (a tier, bundle, fast-action mechanic, price move) prints as LOCKED — fact, not recommendation. The menu proposes only what's still open.
