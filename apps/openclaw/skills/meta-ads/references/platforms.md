# Meta Ads Platform Reference

## Character Limits

### Facebook & Instagram Feed Ads

| Field            | Limit                          | Best Practice                      |
| ---------------- | ------------------------------ | ---------------------------------- |
| Primary text     | 125 chars visible (up to 1000) | Front-load hook in first 125 chars |
| Headline         | 40 chars (max 255)             | Keep under 40 for full visibility  |
| Link description | 30 chars (max 255)             | Short, benefit-driven              |

### Instagram Stories / Reels Ads

| Field        | Limit     | Notes                          |
| ------------ | --------- | ------------------------------ |
| Primary text | 125 chars | Less text = better performance |
| Headline     | 40 chars  | Often hidden on Stories        |

### Facebook / Instagram Carousel

| Field            | Limit             | Notes                   |
| ---------------- | ----------------- | ----------------------- |
| Primary text     | 125 chars visible | Shared across all cards |
| Card headline    | 40 chars          | Per card                |
| Card description | 20 chars          | Per card                |
| Cards            | 2–10              | 3–5 optimal             |

## Image & Video Specs

### Feed (Facebook + Instagram)

- **Image:** 1080×1080 (1:1) or 1080×1350 (4:5) recommended
- **Video:** 1080×1080 or 1080×1350, ≤240 min, ≤4GB
- **File types:** JPG, PNG (image); MP4, MOV (video)

### Stories / Reels

- **Dimensions:** 1080×1920 (9:16)
- **Video length:** Stories ≤60s, Reels ≤90s for ads
- **Safe zone:** Keep text/logos within center 1080×1420 (avoid top/bottom 250px for UI overlays)

### Carousel

- **Image:** 1080×1080 (1:1) per card
- **Video:** 1080×1080, ≤240 min per card

## Targeting Categories

- **Demographics:** Age, gender, location, language, education, job title, industry
- **Interests:** Based on pages liked, content engaged with
- **Behaviors:** Purchase behavior, device usage, travel patterns
- **Custom Audiences:** Website visitors, email lists, app users, engagement audiences
- **Lookalike Audiences:** Based on custom audience seed (1%–10%)
