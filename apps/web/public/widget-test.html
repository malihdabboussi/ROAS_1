Vibey Widget — Dev Test Page

This is a sample host page. Use it to verify the embed widget against your local apps/web + agent-api dev servers.

Required URL params
  • ?slug — your profiles.public_agent_slug
  • &agent — the agent's agent_key
  • &token — the agent's public_page_token (only used in local/dev, never share publicly)
Optional
  • &apiBase — defaults to http://localhost:3003
  • &pageBase — defaults to current origin (the iframe page)

If everything is wired correctly, a launcher button appears in the bottom-right corner.
