## The Core Difference

**Chatting** is hands-on. You and an agent are in a conversation, building something together, steering in real time. Think of it as a working session with a very capable partner.

**Delegating** is hands-off. You write a brief, the team plans the work, and you come back to finished deliverables. Think of it as handing a project to a department.

Most days you will do both. You will chat to think and build. You will delegate to run operations in parallel.

## Chatting (Spaces and Home)

When you chat, you are in a conversation with Vibey or a specific agent. You see streaming responses character by character. You can drop in files, paste links, attach previous artifacts, and iterate.

**You are chatting when you want to:**

- Brainstorm ideas and strategies
- Build an offer, funnel, or ad step by step
- Refine something that was already created
- Have a back-and-forth conversation
- Drop in a file or video and work through it together
- Test how a new agent performs before trusting them with bigger work

Conversations live inside Spaces. The composer on **Home** opens a conversation in your **Personal Space**. The composer on the **Team** page opens a direct conversation with one agent. The composer inside any **Space Channel** opens a group conversation with the team.

## Delegating (Missions)

When you delegate, you are sending a mission. You describe an outcome. Vibey's CEO agent analyzes the mission, breaks it into subtasks, assigns each subtask to the right specialist, and orchestrates the handoffs.

**You are delegating when you want to:**

- Send a multi-step deliverable that needs several agents
- Run the same work in parallel across many items
- Have agents work while you focus on something else
- Run a recurring operation on a schedule
- Set up an outcome that Autopilot can monitor and re-trigger

Missions live inside Spaces too. They show up in the Missions view, in the Docs view as they produce deliverables, and on Home in the Waiting on You card when they need your input.

## The Decision Guide

| I want to... | Go to |
|---|---|
| Brainstorm an idea | Home: talk it through with Vibey |
| Build a funnel from scratch | Home or a Space: ask Vibey to start the Build Funnel flow |
| Hand off a content task | Inside a Space: send a mission |
| Check mission progress | The Missions view inside a Space, or Home: Waiting on You |
| Refine an agent's output | Team page: chat with the agent directly |
| Train an agent with new knowledge | Brain page: open that agent's brain |
| See finished work | Inside a Space: Docs view |
| Build a custom view of your data | Inside a Space: add a Reporting view |
| Create a new project | Spaces: create a new Space |
| Upload documents to your knowledge base | Brain |

## The Mental Model

**Chatting** = you and an agent in a room, whiteboarding together. You are hands-on.

**Delegating** = you are the CEO. You set the strategy, delegate to your team, and check the results.

Most power users switch between both throughout the day. Start in chat to plan and refine. Switch to missions to delegate and let the team execute.

<Callout type="tip">
  Navigate between Home, Team, Spaces, Brain, and Settings directly from the sidebar.
</Callout>
