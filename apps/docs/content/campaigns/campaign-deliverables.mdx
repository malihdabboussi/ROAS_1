## Your Campaign's Library

The Deliverables tab on your [Campaign Dashboard](/campaigns/campaign-dashboard) is the library of everything your agents have produced for that campaign. Every time an agent finishes a [mission](/missions/what-are-missions) subtask, the output lands here.

## Where to Find Deliverables

Deliverables show up in three places:

1. **Campaign Dashboard → Deliverables tab** All deliverables for that campaign in one searchable, sortable library
2. **Inside the Space's [Docs view](/spaces/docs)** Every deliverable from missions in that Space appears in the unified Docs library
3. **Mission detail** Click any mission to see the deliverables it produced

## Deliverable Types

| Type | Examples |
|---|---|
| **Doc** | Research briefs, blog articles, strategy documents, guides |
| **Text** | Ad copy, social post text, email drafts, outlines |
| **Image** | Ad banners, social graphics, hero images, thumbnails |
| **Video** | Generated videos, edited clips, screen recordings |
| **PDF** | Formatted reports, presentations exported as PDF |
| **File** | Spreadsheets, slide decks, audio files, any other format |

## What You Can Do

### Preview

Click any deliverable to open it in a preview modal. Documents and text render as formatted content. Images, videos, and PDFs display inline. Every deliverable shows the agent who created it and the mission it came from.

### Download

Download any deliverable directly:
- **Documents** can be downloaded as Markdown
- **PDFs** download as PDF files
- **Images, videos, and files** download from their URL
- **Copy link** to share the file URL

### Add to a Brain

This is the key to compounding quality. When an agent produces something excellent:

1. Open the deliverable
2. Click **Add to Brain**
3. Pick the target: [Company Brain](/brain/company-brain) (organization-wide), [Agent Brain](/brain/agent-brain) (one role), [Customer Brain](/brain/customer-brain) (real customer signals), or [User Brain](/brain/user-brain) (personal)
4. It becomes a knowledge node in the chosen brain

Next time an agent works on a similar task, they will reference this deliverable. The more great work you feed back, the better every future output becomes.

<Callout type="tip">
  You can only add deliverables to a brain when the parent mission is marked as Done. This ensures you are feeding approved, quality work back into the knowledge base, not draft output.
</Callout>

### Trace to Mission

Every deliverable is linked to the mission and subtask that created it. From the deliverables library, you can see which mission produced each piece of work. Click through to the [mission detail](/missions/what-are-missions) to see the full context: the original brief, the plan, subtasks, activity timeline, and comments.

## Search and Organize

The deliverables library supports:

- **Search** by deliverable title, content, file name, mission title, or type
- **Sort** by date or relevance
- **Grid or list view** toggle
- **Filter** visually by scanning type badges (doc, image, video, pdf, file)

## The Quality Loop

The deliverables system is designed for iteration:

1. **Delegate** work through [missions](/missions/what-are-missions)
2. **Review** deliverables when they come back
3. **Feed back** excellent work to the right [brain](/brain/how-the-brain-works) (Campaign, Company, Agent)
4. **Refine** agent [skills](/team/agent-skills) based on what is working
5. **Delegate again**. Next round is better because agents have better references

This loop is what separates teams that get generic output from teams that get consistently excellent, on-brand work.
