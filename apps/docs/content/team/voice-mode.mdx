title: "Voice Mode"

---

## How to Start

1. Open any agent from the **Team** page
2. Click the **microphone icon** in the message composer
3. The agent connects and starts listening

You will see a voice orb that reacts to who is talking: it pulses when you speak, animates when the agent responds, and shows a distinct state when the agent is running a tool.

## What Happens During a Session

The conversation flows like a phone call. You speak naturally and the agent responds in real time. The agent can do everything in voice that it can do in chat. If you ask your copywriter to write a headline, they will write it. If you ask Vibey to delegate something, that happens. Tools run in the background while you are talking.

## Controls

| Control | What it does |
|---|---|
| **Mute** | Silences your microphone without ending the session. The agent stays on the line. |
| **End** | Ends the voice session and returns to text chat. |

A timer shows how long the session has been active.

## Transcripts

Everything said during a voice session is saved as real messages in your conversation history, exactly as if you had typed them. When you return to text chat, the full voice transcript is right there. No separate logs, no lost context. Voice and text messages are fully interleaved in the same conversation thread.

## Tips

- Make sure your browser has microphone permission enabled for Vibey
- Voice sessions work with one agent at a time. To switch agents, end the current session first
- If the connection drops, you will see an error state with a **Try Again** button

<Callout type="tip">
  Voice mode is especially useful for brainstorming sessions, giving feedback on agent output, and working through complex ideas where typing feels too slow.
</Callout>
