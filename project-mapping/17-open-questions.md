## Method Note — What "Unclear" Means Here

Nothing in this file is a gap in effort; each entry is a genuine limit of static analysis. Three constraints shaped the whole exercise:

1. **No authenticated session.** No credentials were available, and the configured database may be production, so nothing behind a login was exercised. This is the single biggest source of Tier 3–6 uncertainty.
2. **No live database access.** The Supabase MCP was unavailable, so the entire database map was reconstructed from 937 migration files — which the repo's own `roas-drift-recovery.sql` proves are incomplete.
3. **No production environment access.** Every feature flag in Tier 4 has a default in code but an unknown deployed value.

Resolving items **1, 2, and 35** would close roughly half of this list.
