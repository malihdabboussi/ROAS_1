📝 How to add or update a page

  • Copy _template.html into the right category folder and fill in the header block: last updated, category, Linear link, source of truth.
  • Write plain words first. Wrap file paths and line numbers in class="tech" so they only show with the switch.
  • Update an existing page instead of creating a new one when the topic already exists. Bump its date.
  • Add the page to its category index and to the "Recently changed" table above.
  • Full rules are in documentation/wiki/README.md.
