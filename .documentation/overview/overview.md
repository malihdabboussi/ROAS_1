## How It Works

### Studio — The Conversation Interface

1. Describe your goal — your offer, audience, channel
2. Vibey builds in real time — assets materialize as structured, editable deliverables
3. Iterate by talking — change copy, swap sections, adjust tone. The artifact updates live
4. Deploy — push live to your custom domain with one click

### The Brain — Three Layers of Compounding Knowledge

| Layer | What It Stores | How It Compounds |
|-------|---------------|-----------------|
| **Your Brain** | Business context, brand voice, positioning, preferences | Vibey gets better at being YOU over time |
| **Campaign Brain** | Research, competitors, audience insights, uploaded files, URLs | Each campaign builds on everything before it |
| **Agent Brains** | Per-agent specialist knowledge — copywriter's style, developer's patterns | Each specialist improves independently |

This isn't just "chat history." It's a structured knowledge system that connects ideas, finds patterns, and cross-references across everything. Campaign 5 benefits from everything learned in campaigns 1-4.

Every Vibey user gets a team of AI agents, each one a real specialist:

| **Ivy** | Copywriting — emails, landing pages, headlines, scripts, ad copy |

Each agent has:
- **Its own persistent brain** — teach the copywriter your voice once, it knows forever. Teach the designer your brand once, it remembers across every campaign.
- **Attachable skills** — modular workflows you can add, remove, or create. Agents can even create skills for other agents.
- **Enforced authority** — real permission controls. The copywriter can't deploy code. The developer can't publish ads. The analyst can read data but can't change your strategy.
- **Performance tracking** — after missions, agents get scored on quality and reliability.

This isn't "one AI with different prompts." Each agent has different tools, different permissions, different knowledge, and different expertise that compounds over time. Like a real company.

### The Cloud Computer

Every user gets a dedicated machine in the cloud — not shared, not temporary. This machine has real software installed:

- **Video editing** — trim, merge clips, extract audio, add soundtracks, resize, convert between formats
- **Video generation** — create videos using AI (multiple providers)
- **Video analysis** — extract frames, transcribe speech, summarize content
- **PDF generation** — real layouts with fonts, colors, images (not just formatted text)
- **Image generation** — for ads, social posts, branding, presentations
- **App building** — create project codebases, import from GitHub, build custom tools
- **Web search** — real-time research across the internet

This machine runs whether your laptop is on or off. It processes your media, generates your assets, and executes your work 24/7.

### Mission Control — The Command Center

Missions are how work gets organized and executed:

- **Missions** — Strategic objectives with subtasks, priorities, dependencies, deadlines
- **Kanban Board** — Visual drag-and-drop (planning → todo → in progress → review → done)
- **5-Phase Lifecycle** — Plan → execute → review → triage → directive
- **Manager/Worker Delegation** — The right specialist gets assigned to the right task
- **Comment Directives** — You comment → Vibey reviews and acts
- **Self-Healing** — Stuck work gets detected and auto-retried with backoff

Missions aren't chat threads that disappear — they're real tracked work that survives if you close your browser, if the server restarts, if anything goes wrong. Work never gets lost, never gets duplicated, and tasks that can run in parallel do.

### Autonomous Operations

- **Background scheduler** — Runs every 15 minutes evaluating all active work
- **CEO awareness loop** — Evaluates signals against strategy, decides: act, notify, or wait
- **Operational planning** — Creates/amends missions autonomously when strategy demands
- **Self-healing** — Stuck work detected and retried automatically
- **North Star guardrails** — Every autonomous decision checked against your defined strategy
  - Result — what success looks like
  - Purpose — why this campaign exists
  - Strategy — how to get there
  - Off-Limits — what we won't do
- **Daily digest** — What happened, what's next

If strategy isn't defined, proactive missions are blocked. Drift is prevented structurally.

## Technical Architecture

| Component | What It Does |
|-----------|-------------|
| **Web Dashboard** (Next.js) | Studio, Mission Control, CRM, Analytics, Settings |
| **Core API** (NestJS) | Business logic, billing, integrations, campaign management |
| **Agent API** (NestJS) | Chat, artifacts, brain, agent RBAC, skill execution |
| **Mission Worker** | Mission lifecycle, scheduler, CEO awareness, outbox dispatch |
| **OpenClaw Gateway** | AI model routing — multi-provider, session-managed |
| **Per-User Compute** (Fly.io) | Dedicated machine per user — suspends idle, wakes on demand |
| **Database** (Supabase) | Postgres, auth, real-time subscriptions, RLS, storage |

### Billing
- Credits-based (200 credits ≈ $1)
- Stripe with auto-recharge and monthly caps
- Organization-level billing with shared credits

### Organizations
- Multi-user with role-based access (owner, admin, creator, editor, viewer)
- Invitations, campaign transfer between members
- Shared workspace context, isolated billing
