# Voice Chat

Every agent on your team has a voice. Click the mic icon in any agent's chat header to start a live voice conversation instead of typing.

## How it works

When you start a voice session, the agent listens to you in real time and responds in its unique voice. The conversation flows naturally — you speak, the agent responds, you can interrupt, and the agent adjusts. Your agents have the same tools and permissions in voice as they do in text. If you ask your copywriter to write a headline, it happens. If you ask Vibey to delegate to the team, that fires. Tools run in the background while you talk — you'll see them appear in the chat thread as they execute.

## Voice sessions know your conversation

Voice sessions inject the full conversation history into the agent's context. If you've been texting back and forth about a campaign and then switch to voice, the agent picks up exactly where you left off. No repeated context. No lost thread.

## How voices are assigned

Each agent has a voice chosen to match their role and personality. Strategic leaders speak in grounded, steady tones. Creative agents in lighter, more expressive ones. The voice is automatically assigned based on the agent's role and avatar, and stored so it stays consistent across sessions.

There are 30 distinct voices available — 12 female and 18 male — each with different tones and pitches (firm, breezy, bright, warm, excitable, smooth, etc.).

## How transcripts work

Everything said during a voice session is saved as real messages in your conversation history. When you switch back to text, the full voice exchange is right there — user messages with your words, assistant messages with the agent's responses, tool calls visible inline. Voice and text are fully interleaved and persistent.

## Tips

- Mute yourself at any time without ending the session. The agent stays on the line.
- Make sure your browser has microphone permission enabled. If blocked, you can fix it via the lock icon next to the URL bar.
