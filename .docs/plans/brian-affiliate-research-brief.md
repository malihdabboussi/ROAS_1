## 7. Risks & Unknowns

### 7.1 IP Ownership Questions
- **Hormozi / Martell / Dean Jackson content**: These are public frameworks Brian curated, but distributing them inside a paid product may need legal review. Consider stripping to Brian-authored-only for the template, or framing as "Brian's interpretation of" these frameworks.
- **VIP 1-1 recordings**: Contain client PII (Abram, Coen, Hailey, etc.). Must NOT be distributed. Exclude from any template brain.
- **Internal meetings**: Team meetings, AI Setter Meeting, SALES MEETING — internal operational content. Exclude.

### 7.2 Agent Brain Seeding Gap
The `mastermind_coach Brain` only has 5 memories. The `client_success Brain` has 0 memories. All the real knowledge lives in the Default Brain. For the template to work, the coaching agents need their own brain subsets seeded from the Default Brain's relevant memories. This is a data migration / brain-split task.

### 7.3 Schema Drift
- `snapshot_count` on `ns_brains` table shows 0 for the Default Brain, but there are 109 real snapshots in `ns_snapshots`. The counter is not being maintained. Not blocking, but worth fixing.
- `ns_perspectives` and `ns_belief_patterns` have 0 rows for Brian. The brain analysis pipeline hasn't run perspective/belief detection for his account. These would add depth to the template brain if populated.

### 7.4 No Workspace Template Primitive
Vibey has the pieces (agent_templates, skill_library, org_brain_sharing, promo_codes) but no single "workspace template" entity that bundles agents + skills + brain seed + campaigns + widgets into one deployable unit. This is the primary engineering work.

### 7.5 No Affiliate Tracking Infrastructure
`promo_codes` can track basic attribution. But there's no `affiliate_partners` table, no rev-share calculation, no affiliate dashboard. If we go beyond a manual promo code, this needs building.

### 7.6 Mastermind Coach Memory Rules
The 5 memories in the mastermind_coach brain are operational rules, not knowledge:
- Don't advise DM ads until 400+ new followers/day from follower campaigns
- Change only one thing at a time
- Generate daily reports identifying struggling vs thriving students
- Don't give pricing advice unless asked
- Pricing constraint applies to Telegram bot users too

These are critical behavioral guardrails that must ship with the template.
