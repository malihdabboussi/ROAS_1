# Cost Tracking Guidelines

Every external API call that costs money MUST be tracked. No exceptions.

---

## Rule

**EVERY cost-generating call MUST be tracked in `ai_usage_events`.** If a new API call that costs money is added without billing, the `billing_health_log` table and admin dashboard Billing Health tab will show the gap.

For new code, use the `trackBilledCost()` wrapper from `@vibey/api-shared`. For existing code, billing is done via `processDirectTextUsage`, `processImageUsage`, `processFixedCostUsage`, or `processTranscribeUsage` on the `CreditsService`.

---

## What Counts as Cost-Generating

| Provider      | Type        | Examples                                                   |
| ------------- | ----------- | ---------------------------------------------------------- |
| OpenRouter    | Text LLM    | Chat completions, ad concepts, TSX repair, funnel repair   |
| Google Gemini | Text LLM    | Brain extraction, crystallization, conversation processing |
| Google Gemini | Embeddings  | Memory search, document ingestion, brain graph             |
| Google Gemini | OCR         | Image text extraction for brain/documents                  |
| Google Gemini | Image gen   | Imagen 4, Gemini Image Preview                             |
| Google Veo    | Video gen   | Veo 3.1 video generation                                   |
| Deepgram      | STT         | Audio/video transcription (nova-2, nova-3)                 |
| Replicate     | Image/Video | Kling video, Replicate image models                        |
| ScrapCreators | Scraping    | Instagram profile, TikTok profile, transcripts             |

## How to Use `trackBilledCost()`

Import from `@vibey/api-shared`:

```typescript
import { trackBilledCost } from '@vibey/api-shared'
```

### Text LLM (OpenRouter / Gemini)

```typescript
const { result } = await trackBilledCost(
  {
    feature: 'media',
    action: 'generate_ad_concepts',
    serviceType: 'text',
    userId: user.id,
    modelName: 'anthropic/claude-opus-4.6',
  },
  async () => {
    const res = await fetch('https://openrouter.ai/api/v1/chat/completions', { ... })
    const json = await res.json()
    return {
      result: json.choices?.[0]?.message?.content,
      costData: json.usage
        ? {
            type: 'text',
            usage: {
              input: json.usage.prompt_tokens,
              output: json.usage.completion_tokens,
              cacheRead: 0,
              cacheWrite: 0,
              totalTokens: json.usage.total_tokens,
            },
          }
        : undefined,
    }
  },
  this.creditsService,
  this.supabase,   // for billing_health_log on failure
)
```

### Image Generation

```typescript
const { result } = await trackBilledCost(
  {
    feature: 'media',
    action: 'generate_image',
    serviceType: 'image',
    userId,
    modelName: 'imagen-4.0-generate-001',
  },
  async () => {
    const imageUrl = await this.imageService.generate(prompt)
    return { result: imageUrl, costData: { type: 'image' } }
  },
  this.creditsService,
  this.supabase,
)
```

### Video Generation

```typescript
const { result } = await trackBilledCost(
  {
    feature: 'media',
    action: 'generate_video',
    serviceType: 'video',
    userId,
    modelName: 'veo-3.1-fast',
  },
  async () => {
    const videoUrl = await this.videoService.generate(prompt)
    return { result: videoUrl, costData: { type: 'fixed', fixedCostUsd: 0.8 } }
  },
  this.creditsService,
  this.supabase,
)
```

### Speech-to-Text (Deepgram)

```typescript
const { result } = await trackBilledCost(
  {
    feature: 'transcribe',
    action: 'transcribe',
    serviceType: 'audio',
    userId,
    modelName: 'deepgram/nova-3',
  },
  async () => {
    const transcript = await this.deepgram.transcribe(audioBuffer)
    return {
      result: transcript.text,
      costData: { type: 'audio', durationMinutes: transcript.durationSeconds / 60 },
    }
  },
  this.creditsService,
  this.supabase,
)
```

### Fixed-Cost APIs (ScrapCreators, etc.)

```typescript
const { result } = await trackBilledCost(
  {
    feature: 'scraping',
    action: 'instagram_profile',
    serviceType: 'fixed',
    userId,
    modelName: 'scrapecreators/instagram_profile',
  },
  async () => {
    const profile = await this.scraper.fetchProfile(username)
    return { result: profile, costData: { type: 'fixed', fixedCostUsd: 0.005 } }
  },
  this.creditsService,
  this.supabase,
)
```

## Service Types

| Type    | When to use                                                    | Billing method                                 |
| ------- | -------------------------------------------------------------- | ---------------------------------------------- |
| `text`  | Any token-based LLM call (OpenRouter, Gemini, embeddings, OCR) | `processDirectTextUsage`                       |
| `image` | Image generation (Imagen, Gemini Image)                        | `processImageUsage` or `processFixedCostUsage` |
| `video` | Video generation (Veo, Kling, Replicate)                       | `processFixedCostUsage`                        |
| `audio` | Speech-to-text (Deepgram)                                      | `processTranscribeUsage`                       |
| `fixed` | Flat-rate API calls (ScrapCreators, any per-call pricing)      | `processFixedCostUsage`                        |

---

## `cost_source` Values

| Value                | Meaning                                                        |
| -------------------- | -------------------------------------------------------------- |
| `provider_direct`    | Actual cost reported by the provider (most accurate)           |
| `openrouter_api`     | Cost fetched from OpenRouter generation API                    |
| `openrouter_calc`    | Calculated from token counts + OpenRouter live model pricing   |
| `gateway_tokens`     | Calculated from gateway-reported token counts + DB pricing     |
| `db_pricing`         | Calculated from token counts + `token_providers_pricing` table |
| `transcript_pricing` | Calculated from OpenClaw transcript file + DB pricing          |
| `fixed_pricing`      | Fixed USD amount per unit (image/video/scrape)                 |
| `runtime_tokens`     | Calculated from runtime-reported token counts                  |
| `estimated_bulk`     | Estimated cost for bulk operations (SK ingestion)              |
| `openrouter_reconciliation_estimate` | Historical OpenRouter correction row tied to original usage day |
| `deepgram_estimate`  | Estimated from audio duration                                  |
| `char_estimate`      | Estimated from character count                                 |

## Where to Check Health

**Admin Dashboard > Finances > Billing Health tab**

Shows:

- Unresolved billing failures (with resolve button)
- Cost source breakdown (which sources are being used)
- Models missing pricing rows (falling back to defaults)
- OpenRouter reconciliation (daily comparison when cron is active)

---

## When Adding a New Model

1. Add pricing rows to `token_providers_pricing` table:
   - `input_tokens_1k`, `output_tokens_1k` (required)
   - `cache_read_1k`, `cache_write_1k` (if model supports caching)
2. Get prices from OpenRouter: `https://openrouter.ai/api/v1/models`
   - OpenRouter prices are **per token** — multiply by 1000 for per-1K
3. Use the wrapper with the correct `modelName`

---

## When Adding a New Provider

1. Use `trackBilledCost()` with `serviceType: 'fixed'` and the known per-call cost
2. Add the provider to this document's "What Counts as Cost-Generating" table
3. Test that billing events appear in `ai_usage_events`

---

## Anti-Patterns

- Direct `fetch` to any AI provider API without `trackBilledCost()` or manual billing
- Calling `processDirectTextUsage` / `processImageUsage` directly without health logging on failure
- Forgetting to return `costData` from the function passed to the wrapper
- Using `serviceType: 'text'` for image/video/audio calls
- Storing model names with `openrouter/` prefix in `ai_usage_events` (strip it first)
- Adding a model to usage without adding pricing to `token_providers_pricing`

---

## Proxy/Streaming Paths (Special Cases)

The high-volume chat and mission proxy paths (`proxyOpenClawResponsesStream`, `proxyOpenClawResponses`, `proxyOpenClawChatCompletions`) handle billing internally because they parse SSE streams or JSON responses from OpenClaw. They cannot use `trackBilledCost()`.

These paths write to `billing_health_log` on failure so the admin dashboard still shows gaps. If you add a new proxy path, follow the same pattern:

1. Extract usage from the response
2. Call `processDirectTextUsage`
3. In the `.catch()`, write to `billing_health_log` with reason `proxy_billing_failed`

## OpenRouter Historical Reconciliation

Use the internal endpoint `POST /api/internal/billing/org-openrouter-reconciliation` for historical OpenRouter corrections. It requires `INTERNAL_API_TOKEN` and accepts `dryRun`, which defaults to `true`.

Required fields:

- `orgId`
- `batchId`
- `windowStart`
- `windowEnd`
- `allocationFactor`
- `batchCredits`

Optional fields:

- `maxVisibleRowCredits` defaults to `2500` and caps each visible reconciliation usage row. The batch total is unchanged; large source buckets are split into smaller rows across the original source time window.

Dry-run responses show the current org balance, source gateway-token buckets, estimated OpenRouter cost, proposed reconciliation rows, projected balance, and whether org auto-recharge should attempt after deduction.

Apply mode (`dryRun: false`) must only run after reviewing dry-run totals. It inserts `ai_usage_events` rows with `cost_source = openrouter_reconciliation_estimate`, timestamps each row on the original source usage day/time window, then deducts org credits through `CreditsService.deductOrgCredits()` so existing org auto-recharge logic can run.
