## Codebase Patterns

### Confirmed Architecture (2026-02-10)
- Brain data in NeuralSnap Supabase (lmwfgqhtogjbqpvzckua), NOT Vibey2.0
- NestJS is single gateway: frontend + Vibey agent both call NestJS
- NestJS brain module uses second Supabase client (NeuralSnap)
- Two auth paths: Supabase JWT (frontend) + service token (Vibey agent)
- Single agent (Vibey) — no multi-agent system
- Production-first: agent brain works in prod, not in dev (VM can't reach localhost)
