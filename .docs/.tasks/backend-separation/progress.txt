## Codebase Patterns

### Current Architecture (Verified 2026-02-13)
- apps/api = NestJS 11 monolith, 17 modules in app.module.ts
- Deployed BOTH on Vercel (vercel.json + api/index.ts) AND VM (PM2 port 3001)
- VM: Hetzner 188.245.41.230, OpenClaw gateway port 18789
- Cloudflare tunnel: api.govibey.com → VM:3001, gateway.govibey.com → VM:18789
- Frontend proxy: apps/web/src/app/api/proxy/[...path]/route.ts → BACKEND_URL

### Key Files
- apps/api/src/app.module.ts — 17 module imports
- apps/api/src/shared/ — 8 files (AuthGuard, decorators, pipes, filters, services)
- apps/api/src/modules/chat/ — 7 files (ChatModule, OpenClawProxy, ArtifactExtractor)
- apps/api/src/modules/billing/ — 5 files (CreditsGuard, CreditsService, StripeService)
- apps/api/src/modules/brain/ — 18 files (controllers, services, repositories)
- apps/web/src/app/api/proxy/[...path]/route.ts — universal frontend proxy

### Critical Discovery: CreditsService Reads VM Filesystem
- credits.service.ts lines 80-163: reads OpenClaw transcript JSONL files
- Path: OPENCLAW_SESSIONS_DIR = ~/.openclaw/agents/vibey/sessions
- This MUST run on VM (co-located with OpenClaw)
- Balance queries are pure Supabase (work anywhere)
