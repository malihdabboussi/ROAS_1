### Checkout Flow Pattern
- Frontend sends planSlug (e.g., "pro") + billingPeriod ("monthly" | "annual")
- Backend constructs slug: `${planSlug}-${billingPeriod}` → looks up in subscription_plans table
- Creates Stripe Checkout session with plan's stripe_price_id
- Webhook (checkout.session.completed) upserts user_subscriptions

### Webhook Pattern (subscription.updated)
- stripe.service.ts handleSubscriptionUpdated() already handles plan changes
- Updates: status, stripe_subscription_id, stripe_customer_id, current_period_start, current_period_end, cancel_at_period_end
- This means switching interval via stripe.subscriptions.update() will be auto-handled by webhook

### Database State (Verified 2026-02-13)

- All stripe_price_id values are NULL — need to be set after creating Stripe products

### Plan Slug Convention
- Free: "free" (no interval suffix)
- Paid: "{tier}-{interval}" e.g., "pro-monthly", "pro-annual"
- Checkout resolves: planSlug="pro" + billingPeriod="monthly" → slug="pro-monthly"
