## Codebase Patterns
- Manage access pattern in web: gate pages using `useUserRole()` + `canAccessManage()` and redirect unauthorized users to `/studio`.
- Existing Manage shell nav lives in `apps/web/src/components/layout/Sidebar.tsx` under `workspaceNavItems`.
- Backend task style in `apps/api`: module + controller + service split with role guards (`AuthGuard`, `RoleGuard`, `@Roles('power','admin')`).
- Queue worker already has BullMQ root config with retries/backoff in `apps/queue-worker/src/app.module.ts` (attempts: 3, exponential delay 60000ms).
- OpenClaw gateway integration pattern exists in spec `.docs/specs/VIBEY-AGENT-INTEGRATION.md` using `/v1/chat/completions` and session keys.
