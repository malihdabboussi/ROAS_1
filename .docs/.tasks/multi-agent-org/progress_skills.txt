## Codebase Patterns
(Patterns discovered during this task will be added here)

- OpenClaw file watcher mechanism: OpenClaw uses `chokidar` in `apps/openclaw/src/agents/skills/refresh.ts` to watch for `SKILL.md` changes. Writing directly to disk is sufficient to trigger a hot-reload of skills.
- Default skill paths: `/app/agents/[agent_name]/skills/[skill_name]/SKILL.md` inside the Docker container.
